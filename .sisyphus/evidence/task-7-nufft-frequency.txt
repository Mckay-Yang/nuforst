NUFFT Strategy Documentation — Task 7
=======================================

Python NUFFT usage (src/nufrost.py, lines 1062-1067, 1371-1377):
    x = 2*pi*(t_rel - t_rel.min())/Tspan - pi          # map to [-pi, pi]
    c = yy_scaled.astype(np.complex128)
    ms = next_even(nufft_modes)
    Fk = finufft.nufft1d1(x, c, ms, eps=eps, isign=-1) # type-1 NUFFT
    k = np.arange(-ms//2, ms//2)
    freqs = k.astype(np.float64)/Tspan                   # uniform freq grid

The NUFFT type-1 computes:
    F_k = SUM_j c_j * exp(-i * k * x_j)   for k = -M/2 ... M/2-1

This is the exact (non-uniform) Discrete Fourier Transform — finufft
provides an O(N log N) fast algorithm, but the mathematical output is
identical to a direct O(N*M) sum.

Rust Implementation
-------------------
fn compute_spectrum_direct(t_rel, yy, modes, y_scale) -> (freqs, power)

Implements the direct sum:
    for each k in [-M/2, M/2]:
        F_k = SUM_j c_j * exp(-i * k * x_j)

For the per-pixel time series in our test fixtures (N <= 200 obs,
M = 4096), this is fast enough.  The direct sum is mathematically
equivalent to finufft.nufft1d1 up to f64 roundoff.

Frequency Selection Parity
--------------------------
The direct DFT spectrum matches finufft on all three synthetic
fixtures:
  - simple_harmonic: same peak frequencies selected
  - gaps_outliers: same peak frequencies selected
  - step_break: same peak frequencies selected

Any platform-specific f64 rounding differences are bounded by
the test tolerances (atol=1e-6, rtol=1e-5).

Future Pure-Rust NUFFT Replacement Plan
----------------------------------------
If performance becomes a bottleneck (e.g., when processing very
long time series with N >> 200):

1. Rust FFI binding to libfinufft (C library)
   - finufft already provides a C ABI: finufft1d1(...)
   - Can be called via Rust's `extern "C"` FFI
   - Requires libfinufft to be installed on the build machine

2. Pure-Rust port of the FINUFFT algorithm
   - Substantial effort (spreading, interpolation, FFT)
   - Lower priority: direct DFT is fast enough for pixel-level
     time series

The function signature `compute_spectrum_direct()` is designed so
an FFI-backed `compute_spectrum_finufft()` can be swapped in
without changing the frequency selection pipeline.
