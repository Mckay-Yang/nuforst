## 5. Memory Bounding

- read_all_bands() reads full 3D cube into memory: O(bands × rows × cols × 8 bytes)
- For small windows (5×5×10 = 250 doubles ~2KB) this is negligible
- Code structured with read_all_bands() as a separate function so future
  tile-based processing can swap in windowed reads without changing algorithm logic
- Parallel processing uses rayon over rows with thread-local time-series buffers
  (2 Vecs of n_bands f64 per thread — negligible for any realistic band count)
