## Subcommand interface
nufrost-cli full-scene
    --source-name <sentinel-2|hls>
    --lon <float>
    --lat <float>
    [--output-root <path>]         default: data/output
    [--data-root <path>]           default: data
    [--methods <list>]             default: nufrost,hants,zhu2015
    [--n-jobs <num>]
    [--window-size <pixels>]
    [--min-valid-ratio <float>]    default: 0.9
    [--late-fraction <float>]      default: 0.25
    [--frequency-selection <str>]
    [--spectral-top-k <num>]
    [--preferred-top-k <num>]

## Orchestration flow (run_full_scene)
1. discover_sentinel_band_stacks(data_root, lon, lat) → BTreeMap<String, Vec<PathBuf>>
2. For each band, load all chunks: read_all_bands[_window] + extract_raw_band_descriptions
3. Concatenate along time axis into per-band cubes and ISO timestamp lists
4. mask_invalid_sentinel2 on each band cube
5. choose_shared_target_timestamp → target_time (ISO string)
6. make_masked_time_series per-band → masked cubes + ground truth arrays
7. Build shared frequency pool if spectral_top_k/preferred_top_k specified
8. For each method, parallel per-band reconstruction via rayon:
   - Convert ISO string timestamps to relative days
   - Per-pixel nufrost_pixel / hants_pixel / fit_predict_pixel
9. write_band_stack for each method → merged multi-band prediction GeoTIFF
10. write_band_stack for ground truth
11. Write summary JSON with Python-compatible fields
